📐 What this program is — and how it differs from the reference course

This is the graduate track: Course 0 → 6 + a defended capstone, built one unit at a time, gated on demonstrated mastery. Every unit carries multiple lectures, a primary-source reading walkthrough, full derivations, worked examples on the Leitfaden's own parameters, an R implementation, and a graded problem set — numeric (hand + R, tolerance-checked), blank-page derivations, find-the-error, transfer tasks, teach-back, and an adversarial viva. Multiple-choice recognition is deliberately not the assessment here.

A complete 17-module reference course also lives in this repository — use it as background reading and a coverage map. This graduate program is the primary, assessed track.

Mastery dashboard

Progress is stored locally in your browser. Threshold 85 %, soft gate: below it you get targeted remediation and a spaced re-test, but advancement is your call. Confident-but-wrong answers are penalised in calibration; missed topics are resurfaced on an expanding schedule.

⚖️ The one rule that runs through every number

For every fixed parameter you meet — M = 2,5, the LGDs 45 / 45,5 / 54,4 / 55,8 / 12,5 %, the FX-elasticity 1,9, the CVA scalars 0,71 / 1,33, op-risk 5 / 15 %, the 5 % buffer, the +200 bp shift, the 60 % RLB option, materiality 100 / 500 + 1 % — the program states whether it is a regulatory value the CRR/EBA forces, or an ÖRS modelling decision taken for proportionality, and what it trades off. That distinction is the core of what you must defend.
